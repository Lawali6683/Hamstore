What to check if an order is missing

  1. Run hamstore_orders_fix.sql in Supabase SQL Editor once. It creates the place_order function that checkout uses.
  2. Make sure the payment account is saved in Payment accounts. Without one, checkout refuses the order.
  3. Make sure Online buying is on. If it is off, checkout refuses the order.
  4. Place a test order, then press Refresh here.
